# Animated Split-Screen Login & Signup Form

A sleek, highly optimized authentication interface featuring modern floating label transitions and an advanced diagonal split-screen slide animation. Built purely with semantic HTML5, vanilla CSS3, and native JavaScript DOM manipulation.

## 🚀 Features
- **Dynamic Floating Labels:** Labels seamlessly scale and transition into position upon input focus.
- **State-Driven Split Screen:** An advanced CSS `clip-path` panel slides across the screen to transition between Login and Signup modes.
- **Performance Optimized:** Uses native JavaScript asynchronous timing (`setTimeout`) synchronized perfectly with hardware-accelerated CSS animations.
- **Architectural Excellence:** Leverages modular state management cleaner helper functions (`ClearState`, `ClearAnimationClasses`) to ensure memory safety and zero visual bugs during rapid loops.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for optimal accessibility.
- **CSS3:** Custom animations, keyframes, transitions, and layout manipulation (`clip-path`, `flexbox`).
- **JavaScript (ES6):** Event listeners, active-element DOM tracking, and orchestrated state switching.

## 🔧 Installation & Usage


2. Open `index.html` directly in any modern browser to view the interface locally.
